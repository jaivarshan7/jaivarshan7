# 🚀 Featured Projects

## 🛒 SmartCheckout

**RFID-Based Smart Checkout & Inventory Management System**

A desktop-based smart checkout system designed to automate product identification and checkout using RFID technology.

**Built with:**

`Python` `PyQt6` `MySQL` `ESP32` `PN532 RFID`

🔗 **Repository:**  
https://github.com/jaivarshan7/SmartCheckout

## 📦 Warehouse Management System

**Multi-Tenant Warehouse Management Platform**

A full-stack warehouse management system with role-based access control, inventory management, order workflows, invoice generation, payment proof management, and tenant isolation.

**Built with:**

`React` `TypeScript` `Vite` `Supabase` `PostgreSQL` `RPC` `RBAC`

**Key areas:**

- Multi-tenant architecture
- Role-based access control
- Inventory management
- Order lifecycle management
- Invoice automation
- Payment proof management
- Client delivery verification

🔗 **Repository:**  
https://github.com/jaivarshan7/Warevo

## 🏠 Smart Water Tank Automation

**IoT-Based Water Tank Monitoring & Pump Control**

An automated water management system using an ESP32 and ultrasonic distance sensing to monitor tank levels and control pumps.

**Built with:**

`ESP32` `C++` `Ultrasonic Sensor` `Relay` `Home Assistant` `ESPHome`

**Features:**

- Real-time water-level monitoring
- Automatic pump control
- Remote control
- Home Assistant integration
- ESP32-based web interface
